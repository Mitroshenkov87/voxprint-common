# image

Shared image save format and metadata. The format is the `image.save_format` suite setting: lossless WebP by default, lossy WebP at a quality of 1-100, or PNG, AVIF, or JPEG. A quality of `None` is unset: `save_image` applies `default_quality` for the save purpose. `QUALITY_LOSSLESS` (the string `"lossless"`) is explicit lossless, even for a regular picture. `default_quality` returns `QUALITY_LOSSLESS` for masters, series, and hand-offs, and quality 90 (`LOSSY_DEFAULT_QUALITY`) for pictures, so `save_image(..., purpose="picture")` with an unset quality saves lossy WebP at quality 90. `save_image` writes atomically and fixes the extension.

Metadata (`prompt`, `seed`, `steps`, `base` with `base_model` accepted on input and read back as both, `lora_strength`, and `loras`) is off unless `write_metadata=True` or the setting's `metadata` key is true. Passed metadata is ignored while that switch is off. It is written as XMP on WebP, AVIF, and JPEG, plus a minimal EXIF ImageDescription and UserComment JSON copy, and as a PNG iTXt chunk keyed `XML:com.adobe.xmp`. A strength that is not a finite float (`inf` or `nan`) is omitted from the packet and reads back as None. `read_metadata` reads that XMP from all four formats. Each LoRA comes back as `{name, strength, sha256, base}`; a missing LoRA base is None. `parse_xmp` returns the empty metadata for a malformed packet and logs a warning instead of raising. Multi-line prompts round-trip, including LF and CRLF. Pillow is an optional extra and is never imported at load.
