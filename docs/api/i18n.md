# i18n

Shared catalogs for suite UI text. English is the source and the fallback. The languages shipped with this package are English, German, Russian, Ukrainian, and Latvian. The JSON files live in `voxprint_common/ui/locales`, beside `tokens.json`.

Audiobook Builder already uses one JSON file per language. Plotweaver and Canvas keep the same shape in dictionaries. Write the dictionary out as JSON and pass the folder to `add_catalogs`. A flat key `menu.open` and a nested object `{"menu": {"open": "Open"}}` both become `menu.open`.

```python
from pathlib import Path

from voxprint_common.i18n import add_catalogs, set_language, tr

add_catalogs(Path(__file__).resolve().parent / "locales")
set_language("ru")
tr("menu.open")
tr("items", count=3)
```

The language is chosen in this order: `ui_language` in the suite settings when the file sets it, then `VOXPRINT_LANG`, then the operating-system UI language, then English. `set_language` changes this process only. `set_ui_language` remembers the choice.

`tr(key, count=n)` selects a plural form. Russian and Ukrainian use `one`, `few`, and `many`. Latvian uses `zero`, `one`, and `other`. English and German use `one` and `other`. A missing form uses `other`.

Splash titles use the same catalogs. `splash.app.<id>` is the brand string, spelled the same in every language. The stage line is not translated inside the splash: pass text that already went through `tr`.

## CI check

Apps run this against their own package. It fails when a Qt or PySide6 call contains a hard-coded user-facing string, when a key is missing from any listed locale, or when `{placeholder}` fields differ between languages. A key nothing references is a warning and does not fail the run. `# i18n: ignore` on the call, on the string, or on the line above the call skips that call. Brand names such as `VOXPrint` and `Hugging Face` are allowed as a whole argument. `--allow` adds another exact string.

```yaml
      - name: Localized UI strings
        run: python -m voxprint_common.i18n.check --src src/<pkg> --locales src/<pkg>/locales --langs en,ru,de,uk,lv
```

The first code in `--langs` is the source catalog. A dynamic key such as `f"mdl.source.{code}"` counts as a use of every key under that prefix.
